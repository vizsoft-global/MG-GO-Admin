2. Order Status slicer (option C, Performance only)
   A new Order status dropdown sits on the slicer row: Pending / In Transit / Verified / All.

3. Date for a non-verified order
   Window day is the Kuwait calendar day of COALESCE(delivered_at, pickup_at, created_at).
   Verified orders still use delivered_at when that column is set.

4. Auto-refresh every 60 seconds
   The dashboard now refreshes itself every 60 seconds. Header Refresh still works.
   It does not refetch just because you come back to the tab.

5. Clear filters
   Clear now also returns Order status to Verified, and the period back to This Month (Partner / Zone / Vehicle / Nationality / Source Type / Company / Restaurant still return to All).

   Recon stays on pending + in transit + verified. This slicer is Performance only.
