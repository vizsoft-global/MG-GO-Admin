MG GO Performance dashboard — verify the 8 SOP fixes

Open https://dpdadmin-prod.vercel.app/en/performance (after deploy). Kuwait dates.

1. Top & Bottom Zones

  1. Open Top & Bottom.
  2. On This Month you should still see a Zones block under Stores. If no zone has orders, the card says “No zone-assigned riders with orders in this period”.
  3. Switch to Last Month. If zones had orders, Top / Bottom Zones appear with N between 2 and 10 (10% of zones, clamped).

2. Outsource Companies table

  1. Open Outsource.
  2. The Companies table should not be empty when Total Riders > 0.
  3. Riders with no Company show as Unassigned company, including 0-order riders.

3. Riders’ Analysis filters

  1. Open Riders’ Analysis.
  2. Every column header has a filter icon and a sort icon. Headers are fully readable (scroll sideways if needed).
  3. Filter a text column: search, tick values, Apply. Filter Orders with Min/Max, Apply. Both stay on together (AND).
  4. Sort cycles: click once ascending, again descending, again back to default (Orders descending).

4. Chart data labels

  1. Walk Overview, DPD & Efficiency, Top & Bottom, Outsource.
  2. Every bar and line should show its value on the chart, not only on hover. Nothing should be clipped off the edge.

5. Default period and Clear

  1. Reload the page. This month is selected (1st → today, Kuwait).
  2. Pick Last 7 days and a Partner. Click Clear filters.
  3. All slicers return to All, and the period returns to This Month.

6. Stores CSV

  1. Open DPD & Efficiency.
  2. On the Americana stores table, click Export CSV.
  3. The file has Restaurant, Zone, Orders, DPD, Riders for the rows on screen.

7. Weekly / Monthly / Year

  1. Stay on This Month. Click Weekly. Trend charts show up to four weeks: 1–7, 8–14, 15–21, 22–today. KPIs do not change vs Daily.
  2. Click Monthly. A Year picker appears. Trend is Jan → the current month of that year.
  3. KPIs, tables and Top & Bottom stay on This Month (or whichever period pill is selected).

8. Data freshness (confirmation)

Sources: verified deliveries (Kuwait delivered_at), drivers, profiles, restaurants, zones, vehicles, monthly Target DPD.

Cache: live query every time. Browser keeps the last result 60 seconds. No auto-refresh. Use Refresh.

Latency: an order counts only after it is verified, then on the next Refresh / filter / reload.
